Store hours

How to change hours

  1. Change the times for any day below. Uncheck Open if the shop is closed that day.
  2. Click Save hours.
  3. That's it. The website shows the new hours right away.

Merch

Quick guide

  1. Add a shirt: click "Add new item", fill in the form, then click Save item.
  2. Change a price or name: click Edit next to the item.
  3. Sold out? Uncheck "Show on site" to hide it without deleting it.
  4. Gone for good? Click Remove.

Help

Step-by-step instructions for the everyday jobs.

Post holiday hours
  1. Click Store hours on the left.
  2. Type the notice in the Holiday box, for example "Closed Christmas Day."
  3. If the times change that week, change them for that day.
  4. Click Save hours.
  5. After the holiday, empty the Holiday box, set the times back, and click Save hours again.
Add a new shirt
  1. Click Merch, then + Add new item.
  2. Type the name and price, and tick the sizes you have.
  3. Add a photo if you have one. If not, pick a color and style for the drawing.
  4. Click Save item. It shows on the Merch page right away.
Change a price
  1. Click Merch, then Edit next to the shirt.
  2. Type the new price.
  3. Click Save item.
Hide a sold-out shirt
  1. Click Merch.
  2. Uncheck Show on site next to the shirt. It disappears from the store but stays saved here.
  3. When it's back in stock, check the box again.
Remove a shirt for good
  1. Click Merch, then Remove next to the shirt.
  2. Click OK to confirm.
